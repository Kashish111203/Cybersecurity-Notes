# Network Devices Notes

**Date:** 05-06-2026

---

# Router

* Connects different networks together
* Uses IP addresses for routing
* Forwards packets between networks

# Switch

* Connects devices within the same network
* Uses MAC addresses
* Reduces collisions

# Hub

* Sends data to all connected devices
* No intelligent forwarding
* Less efficient than switches

# Firewall

* Filters network traffic
* Enforces security policies
* Allows or blocks traffic

# Access Point (AP)

* Provides wireless connectivity
* Connects wireless devices to wired networks

# Modem

* Converts signals between ISP and local network
* Provides internet access

# Load Balancer

* Distributes traffic among servers
* Improves performance and availability

# Proxy Server

* Acts as intermediary between client and server
* Can provide filtering and anonymity
