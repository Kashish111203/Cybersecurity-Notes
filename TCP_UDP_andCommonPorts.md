# TCP and UDP Ports Notes

**Date:** 04-06-2026

---

# What is a Port?

A port is a logical endpoint used by applications for communication.

Device Identification:

IP Address → Device

Port Number → Application / Service

---

# TCP

Characteristics:

* Connection-oriented
* Reliable communication
* Error checking
* Ordered delivery
* Higher overhead

Examples:

* Web browsing
* File transfers
* Email

---

# UDP

Characteristics:

* Connectionless
* Faster communication
* No guarantee of delivery
* Lower overhead

Examples:

* Streaming
* Gaming
* DNS
* VoIP

---

# TCP vs UDP

| TCP                 | UDP            |
| ------------------- | -------------- |
| Reliable            | Faster         |
| Connection-oriented | Connectionless |
| More overhead       | Less overhead  |
